Política de privacidade — Hermes

O Hermes é um assistente pessoal de uso privado. Ele acessa os dados das contas Google do próprio dono (Gmail, Agenda, Drive, Documentos, Planilhas e Contatos) somente com a autorização dele e apenas para executar as tarefas que ele pede.

  • Os dados não são vendidos, compartilhados nem usados para publicidade.
  • Os dados ficam no servidor privado do dono e não são transferidos a terceiros, exceto aos serviços que o próprio dono escolhe usar.
  • O uso de dados obtidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
